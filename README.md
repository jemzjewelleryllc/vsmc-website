# VSMC - Very Specific Medical Centre

Professional healthcare website for chronic anxiety and pain treatment.

## 🏥 Overview

VSMC is a PHIPA-compliant medical practice website serving patients at **Sherway Medical Centre**, Etobicoke, Ontario. The site provides appointment booking, patient intake forms, and referral workflows.

## 🚀 Quick Start

```bash
# Serve locally
npm start

# Development with live reload
npm run dev

# Package for deployment
npm run package
```

## 📁 Project Structure

```
VSMC/
├── index.html          # Main landing page
├── booking.html        # Appointment scheduling
├── intake.html         # PHIPA-compliant patient forms
├── referrals.html      # Physician & self-referral
├── styles.css          # Main styles
├── forms.css           # Form-specific styles
├── script.js           # Main JavaScript
├── booking.js          # Booking page logic
├── openspec/           # Project specifications
└── .github/prompts/    # AI prompts
```

## 🔒 Security & Compliance

- **PHIPA Compliant**: Patient data handling follows Ontario's Personal Health Information Protection Act
- **Content Security Policy**: XSS protection via meta tags
- **Form Validation**: Client-side validation with sanitization
- **Secure Forms**: All forms use HTTPS submission patterns

## ♿ Accessibility

- WCAG 2.1 Level AA compliant
- Semantic HTML5 markup
- ARIA labels on interactive elements
- Keyboard navigation support
- Screen reader optimized
