# VSMC Project Agents

## Project Overview
VSMC (Very Specific Medical Centre) is a healthcare website for chronic anxiety and pain treatment.

## Steering Rules
- Follow PHIPA compliance for all patient data handling
- Use professional medical terminology
- Maintain accessibility standards (WCAG 2.1)
- Ensure responsive design for all devices

## Code Standards
- HTML5 semantic markup
- CSS with custom properties (variables)
- Vanilla JavaScript (no frameworks for static site)
- Progressive enhancement approach
