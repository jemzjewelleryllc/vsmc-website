# VSMC Project Specification

## Overview
VSMC (Very Specific Medical Centre) is a professional healthcare website specializing in chronic anxiety and pain treatment, headquartered at Sherway Medical Centre, Etobicoke, Ontario.

## Features
- **Appointment Booking System** - Multi-step wizard with date/time selection
- **PHIPA-Compliant Patient Intake Forms** - Consent, personal info, medical history
- **Referral Workflow** - Physician and self-referral support
- **Responsive Design** - Mobile-first approach

## Technology Stack
- HTML5, CSS3, JavaScript (ES6+)
- Google Fonts (Inter)
- No build system required (static site)

## Pages
| Page | File | Purpose |
|------|------|---------|
| Home | `index.html` | Main landing page with services and team |
| Booking | `booking.html` | Appointment scheduling |
| Intake | `intake.html` | Patient intake forms |
| Referrals | `referrals.html` | Referral submission |
